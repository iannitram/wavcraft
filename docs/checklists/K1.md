# K1 checklist: Episode Check bench on the 64 GB Linux tablet

Step K1.9 of the roadmap (#1256). This records one run of the K1.8 bench, `crates/core/tests/episode_check_bench.rs`, against the v1 K1 limits.

Measured on 2026-11-17 at commit `ca779577528f2334b3f3c71066824e7a35d929ac` (origin/main), release build.

## Machine

- ASUS ROG Flow Z13 (GZ302EA), AMD Ryzen AI MAX+ 395, 64 GB unified memory (61 GiB visible to Linux)
- SteamOS, Linux 7.2.7-valve2
- Built and run in the `craft-build` container (distrobox), rustc 1.100.0

## Command

```
cargo test -p wavcraft-core --release --test episode_check_bench -- --ignored --nocapture
```

The bench writes an hour of 48 kHz stereo to a temp store, scans it, and measures what the scan adds.

## Result

| Measure | Result | Limit (v1 K1) | Inside the limit |
|---|---|---|---|
| Scan time for one hour of stereo | 12.16 s | under 60 s | yes |
| Peak memory growth over the scan (`VmHWM`) | 10.3 MB | under 200 MB | yes |
| Cancel latency | 0.000004 s | under 1 s | yes |

The test passed: `test one_hour_stereo_scan_is_fast_and_small ... ok`, `1 passed; 0 failed` (24.54 s for the whole test, including writing the file).
