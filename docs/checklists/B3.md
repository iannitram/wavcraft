# B3 checklist: zoom keys and the navigator bar

Step B3.1 of the roadmap: a measurement, not a unit test. The two scripts, tools/alpha/f19.py and tools/alpha/f69.py, drive a release build over the control channel on a synthetic 20 s stereo file and print one PASS or FAIL line per check, then one JSON line. The step passes when each script prints only PASS lines, ends with `"ok": true`, and exits 0. B3.2 (the hand check on Windows) adds its own section below this one.
